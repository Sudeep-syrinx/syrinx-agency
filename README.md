# Syrinx Digital — Next.js, Tailwind CSS & Framer Motion

![Syrinx Digital Studio](/public/agency.PNG)

Syrinx Digital is a high-performance, multi-page agency website engineered with Next.js, Tailwind CSS, and Framer Motion. Built to deliver an immersive digital experience, this site combines clean minimalist design with fluid 3D-inspired animations and interactive UI components.

## Features

- **Modern Architecture:** Clean, responsive multi-page layout built for digital agencies and technology studios.
- **Next.js & Tailwind CSS:** Ultra-fast rendering engine powered by Tailwind's utility-first styling.
- **Fluid Motion:** Engaging micro-interactions, scroll-driven elements, and page transitions powered by Framer Motion.
- **MDX Dynamic Content:** Manage client case studies and technical articles seamlessly using Markdown & React components.
- **Fully Customizable:** Modular component layout built for scaling brand assets, services, and digital portfolios.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Content:** [MDX](https://mdxjs.com/)
- **Icons:** React Icons / Lucide Icons
